Privacy policy

Effective October 17, 2026 · updated for OpenCue 0.3

OpenCue is a desktop app that runs on your computer. It has no account system, no servers of its own and no telemetry. This page explains what stays on your computer and what is sent to services you choose to connect.

What stays on your computer

  • Your agents, their instructions, memory, skills, chats, automations and settings, in the OpenCue data folder (~/Library/Application Support/opencue on macOS, ~/.local/share/opencue on Linux, %APPDATA%\opencue\data on Windows).
  • Files you or your agents share in chats, in that folder's files/ directory and as copies in the agents' workspaces.
  • Secrets — API keys, email passwords and tokens — in a secrets.json file readable by your user alone, and the OAuth tokens of catalog apps in oauth/ (same protection). The system keychain is not used.
  • Files agents create in their workspace folder.

The OpenCue project never receives any of this. There is no analytics, crash reporting or usage tracking in the app.

What leaves your computer, and to whom

OpenCue only talks to the services you configure, when an agent or you use them:

Each of those services handles data under its own privacy policy. Review them before connecting an account.

Local servers

The automation webhook server and the Docker desktop view listen only on 127.0.0.1, so they can be reached from your own computer and not from the network.

Install scripts

install.sh and install.ps1 ask the GitHub API for the latest release, download it from GitHub and install it for your user. They send nothing else and collect nothing.

This website

This site is static and hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may keep standard server logs (such as IP addresses) as described in the GitHub Privacy Statement. The home page loads the three.js library from the jsDelivr CDN for its animation and asks the GitHub API which release is the latest, so those services receive a normal request from your browser. Your operating system is detected in your browser to pick the right download and is not sent anywhere.

Deleting your data

Delete an agent to remove its chat, memory, instructions, workspace and email password. Clearing a conversation removes its messages; shared files stay in the files/ folder until you delete them. To remove everything, quit OpenCue and delete the data folder; API keys can be removed from Settings or your system's credential manager.

Children

OpenCue is not directed at children. Model providers you connect have their own age requirements.

Changes

Changes to this policy are published on this page and in the changelog, with a new effective date.

Contact

Questions: open an issue. Security problems: please report them privately as described in the security policy.
