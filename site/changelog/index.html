Changelog

What's new in OpenCue. Downloads are on GitHub Releases.

0.5.0 October 26, 2026

New

  • Local speech models (Settings → Models → Local): Parakeet, Canary, Whisper and SenseVoice for speech-to-text and Kokoro for voices, running on your computer through the small sherpa-onnx runtime. Settings → Voice picks ElevenLabs or local for each direction.
  • NVIDIA PersonaPlex: the real-time speech-to-speech model, installed and started by OpenCue, with a phone-button option and a QR code to call from a phone on your network (needs an NVIDIA GPU, Python 3.10+ and a Hugging Face token).
  • /plan: an agent plans, then carries the plan out step by step, with a status card showing what it is doing, a segment per step, timings and Approve / Deny.
  • Skills in the chat's +: system commands (/plan, /dashboard, /create-skill, /create-automation, /artifact, /canvas, /ai-council) and, under a separate label, your own. /canvas opens a document you and the agent edit together.
  • Artifact cards with progress while the agent writes, then a clickable card that opens the preview in the side panel.
  • Resizable panels and a button to pop them out into a window you can drag around the desktop.
  • Terminals for Claude Code, Codex, Grok Build, Gemini CLI, Antigravity, Mistral Vibe, Muse Code or a shell, from the sidebar's +.
  • AI council: members answer on their own, review each other anonymously and the chair writes the verdict. A template, a group kind and /ai-council.
  • Coding groups: sessions, changes, pull requests with checks, a worktree per agent, and Claude Code / Codex / Grok as teammates that talk with ACK, STATUS, BLOCKED and DONE.
  • SPACE installs itself on Linux x86_64 with KVM: checks, download, tools, Firecracker, bring-up and sign-in, with the address and token filled in.

Changed

  • The Dashboard button is gone: the OpenCue logo takes you home.
  • Providers are ordered: connected first, then cloud APIs, local models and CLIs.
  • Artifacts open with a click on their card (Settings → General can open them automatically).

Fixed

  • Built-in browser: the page could still cover the address row on macOS; the app now measures where it really is and corrects it.

0.4.2 October 25, 2026

New

  • Artifacts: agents hand you web pages (sandboxed HTML), SVG, Markdown, Mermaid diagrams, code, CSV/JSON and real Excel, Word, PowerPoint and PDF files in a side panel with Preview / Code, versions, copy and save. Every version is a file in the agent's Files.
  • Dashboard: the home screen with what is running, plans, automations, recent chats and usage. Esc in a chat returns to it.
  • /dashboard: in Settings → General → Dashboard pick the agent in charge, then ask it in chat to redesign the page; it is plain HTML the agent rewrites.
  • Copy, edit and regenerate: a copy button on every reply, and Edit / Regenerate on your last message.
  • Mistral API, Groq, Mistral Vibe CLI and Antigravity CLI as providers, with their logos in Settings → Providers.
  • Browser tabs in the built-in browser.

Changed

  • The app opens on the dashboard.
  • Site: Mistral (one logo for API and Vibe), Groq and Antigravity logos added.

Fixed

  • Built-in browser: on macOS the page covered the address bar as soon as it loaded; it now sits below it.

0.4.1 October 21, 2026

New

  • Google Gemini, Meta Muse API and the Muse Code CLI as providers.
  • Complete templates: every template agent comes with a soul, skills and starting memories; the x.ai import sets the soul and maps the avatar to OpenCue's own.
  • Agent-to-agent cards in 1:1 chats: the other agent's name in their color, a dropdown with the question and answer, and an arrow to the full chat. Each request gets its own card.

Changed

  • Templates window: tags in their own row under Agents / Teams.
  • Site: Gemini and Muse logos added; the Codex and Claude CLI logos removed and Grok without the terminal icon.

Fixed

  • Template avatars are always OpenCue's own (no "invalid" ones).
  • Built-in browser: no more flashing over the sidebar and header, and one page per agent.
  • Test notification works every time.

0.4.0 October 20, 2026

New

  • Built-in browser: a Browser tab in the Computer panel that an agent can drive (open, read, click, type) while you watch. Own cookies, new sites ask first, off unless the agent's switch is on.
  • Computer panel: VM and browser on top, terminal below; Files tab removed.
  • WhatsApp (Settings → Messenger): scan a QR, pick the agent; it answers automatically and the chat shows a green WhatsApp card with the question and the answer.
  • Templates for agents and teams, plus an import from x.ai (marketplace bots come with skills, memories and routines).
  • Search every chat with ⌘K.
  • Subscription limits for Codex and Claude Code under Usage: 5-hour and weekly bars with reset times.

Changed

  • Reasoning is a subtle fold above the answer.
  • No image field for Podman in Settings → Computers.

0.3.8 October 19, 2026

Fixed

  • Podman desktop: it now uses Cua's XFCE image (OpenMausBot's) instead of the one that showed a black screen.
  • The chosen VM is respected: an agent set to Docker or Podman no longer opens VMPal.
  • The permission card lines up with the agent's replies in groups.

New

  • Settings → Computers: Stop all VMs, a play button for the start command, desktop view on by default.
  • Reasoning shows as a folded message above the answer.
  • The call button is gray without an ElevenLabs key, with a hint on hover.
  • The chat's + menu lists Agents and Skills on the side.

0.3.7 October 19, 2026

Fixed

  • Permission cards for Claude Code agents: the CLI's own tools (Bash, Read, Edit…) now ask the app, so the Accept / Reject card shows in the chat instead of a "no permission" answer.
  • Podman without Docker: the Local VM option is available with either engine and Podman is used by default when Docker is not installed.
  • Catalog sign-in: long OAuth links now open in your browser ("Not allowed to open url" is gone).
  • Claude Code agents now show the "Chat with …" card when they talk to another agent.

New

  • Stop button for local VMs in the Computer panel.
  • Live agent conversation: a card with a moving green border follows what two agents say to each other.
  • Composio is the first card in the Catalog; Gmail, Drive, GitHub and Outlook sign in through it when you have no OAuth key of your own, and the apps it connects show as blue tags. Google Calendar now comes through Composio. Card status moved to the bottom.
  • The website shows your provider logos in black, readable in light and dark themes.

0.3.6 October 19, 2026

New

  • Podman as an alternative to Docker for Local VMs: a switch in Settings → Computers, a setup checklist that follows it, and a per-agent choice.
  • Catalog instead of Composio: Gmail, Google Drive, Google Calendar, Notion, Trello, GitHub, Supabase, Vercel and Outlook as cards with a moving border (red not connected, yellow connect again, green connected). Touch one to sign in with OAuth in your browser; OpenCue comes back by itself. Turn each app on per agent.
  • The terminal opens by itself when an agent runs a command, so you can watch the commands and the VM.
  • Right-click an agent or group: rename, pin, clear chat, reset chat, delete.
  • Voice calls: a phone icon in the agent's header opens a phone-sized window; just talk, interrupt any time, mute or hang up.

Removed

  • Composio.
  • The system keychain: secrets now live in a private file (secrets.json, mode 0600). Enter your API keys again after updating.

0.3.5 October 19, 2026

New

  • Agents talk to each other in 1:1 chats, no group needed: an agent asks another one and gets the reply back. The chat shows a Chat with … pill that opens their conversation. Type @ to pick the agent you want it to ask.
  • Ask and permission cards: a yellow, animated frame with the request and a text field or Accept / Reject. Agents get an ask_user tool, and CLI agents now ask instead of being refused in Ask-first mode.
  • Shared or per-agent Docker VMs, an idle stop that keeps files and apps, and a setup checklist: install Docker, start it, download the desktop, create the VM.
  • A refresh button next to Save in Composio reloads the connected apps.

Fixed

  • Claude Code agents no longer hit permission errors on Composio: the CLI only sees OpenCue's tools, not your other MCP servers.

0.3.4 October 18, 2026

New

  • Composio keys that work: a consumer key (ck_…) connects through Composio Connect with the right header; project keys (ak_…) keep using Composio's API. Connect an app straight from Settings.
  • Local VM options for each agent: live desktop, memory, CPUs and a VM folder you choose that keeps the machine's home, so nothing is lost when the app closes or the VM stops.
  • Perplexity SPACE is named as such, with a link to its GitHub repository.
  • Provider logos on this website, in light and dark.

0.3.3 October 18, 2026

New

  • Working folder for each agent: see where it works (its own folder by default) and point it at any folder on your computer.
  • Connect an app now lists the apps Composio offers: touch the field to see them, type to search.
  • Links are pills: a small rounded pill with the site's name and an arrow out.
  • A sturdier agent loop: a stable prompt prefix, long tool results saved to files, automatic summaries of long conversations, a plan the agent keeps in view, helpers with a clean context (research) and a guard against repeating the same call.

Changed

  • The Claude Code, Codex and Grok CLIs list the models they accept, and an expired sign-in says how to renew it.

Fixed

  • Composio 401: keys are sent in the header their type needs (x-api-key, x-consumer-api-key or x-user-api-key).
  • Short replies no longer wrap into a narrow bubble.

0.3.2 October 18, 2026

New

  • Base system prompt for every agent: it knows it is an agent inside OpenCue, with tools, memory and skills. It sits before your own instructions and is not shown in the app.
  • A new agent asks what its job will be and writes its own profile from your answer: instructions (what it does) and a new soul (SOUL.md: personality, tone, values), kept up to date as you talk. Both are editable in its profile.
  • Grok CLI: a provider that runs your installed, logged-in grok (xAI Grok Build).
  • System notifications in Settings → Notifications: finished replies and approval requests while OpenCue isn't in front.
  • Tray menu: app name and version on top, then Open, Settings, Check for Updates and Quit.
  • VMPal as a computer option, above "This computer", in an agent's Computer page.
  • Resizable panels: drag the edge of the agent list and of the agent settings; widths are remembered.

Changed

  • Messages start and end at the width of the header and the chat input.
  • Claude Code and Codex agents get the VMPal machines you picked; the Claude, Codex and Grok CLIs list the models they accept.

Fixed

  • CheaperInference had the wrong name and address; existing providers are migrated.
  • Claude Code and Codex now run from the installed app (the Dock/Finder PATH didn't include them).
  • Local models can control a VMPal machine: unique tool names and clear steps to start the VM and allow agent control.
  • No more horizontal scroll in an agent's settings panel.

0.3.1 October 17, 2026

New

  • Walkthrough: on first launch a floating window takes you through your name, a few lines about you, connecting a provider, picking a default model and creating your first agent. Replay it from Settings → General.
  • Providers and Models are separate. Providers shows a container for every supported provider; Models lists the models of the ready ones with a search bar and a switch to show or hide each one (or all at once). Hidden models vanish from every picker.
  • Choose the model when creating an agent, right in the Create Agent window.
  • VMPal machines: add them as TOML ([mcp_servers.vmpal-…]) in Settings → Computers, then pick them per agent — or paste a new one from the agent's Computer page.
  • Slash commands: type / in the chat to run a skill, or use /create-automation and /create-skill so the agent builds them itself.
  • Memory builds itself: automatic learning is on by default, shares what every agent should know, avoids duplicates and tidies long memories.
  • About me in Settings → Account: a description every agent reads as background.

Changed

  • The avatar picker is a floating window that fills its width, with faces on the avatar's color for proper contrast.
  • The chat input is as wide as the header.
  • Dropdowns, confirmations, tooltips and the right-click menu are drawn by the app instead of the system.

0.3.0 October 17, 2026

New

  • macOS: a universal app (Apple silicon and Intel) and .dmg, built by GitHub Actions with every release.
  • One-line install: curl -fsSL https://lautaro005.github.io/opencue/install.sh | sh on macOS and Linux, irm https://lautaro005.github.io/opencue/install.ps1 | iex on Windows. Then start OpenCue with opencue.
  • Files in chats and groups: attach with + → Files, drag and drop or paste. Agents see pictures, get small text files inline and find every file in their workspace under files/. New share_file tool lets agents send files back. Files pages for agents and groups.
  • OpenCue tools for Codex and Claude Code agents: CLI-backed agents now get memory, web, skills, their computer, files, email and Composio through MCP (opencue mcp-serve). Actions that need approval are refused in Ask-first mode.
  • Desktop view for Docker computers: a web desktop (Webtop by default; any noVNC, KasmVNC or Selkies image) in a new Desktop tab, published on 127.0.0.1 only. Restart computer keeps the workspace.
  • Automatic updates: signed updates from GitHub Releases, a note in the sidebar and Install and restart in Settings → About.
  • Connect Composio apps from OpenCue: Gmail, Calendar, Slack, Notion, GitHub, Drive or any other app, from Settings → Apps.
  • Gmail automations: “New email” triggers now work with Gmail accounts connected through Composio.
  • Readable schedules: “Weekdays at 9:00” instead of 0 9 * * 1-5, also while you type.
  • opencue --version; opencue-cli mcp-serve; a macOS build of opencue-cli.
  • Website: new home page with a 3D animation, download button that detects your system with install steps, and llms.txt.

Changed

  • Releases are published right away instead of as drafts, so the installers and updater find them.
  • The app binary is called opencue on every system.
  • The microphone permission prompt on macOS explains what it is for.

0.2.0 October 17, 2026

New

  • New look for agents: drawn avatars — a colored shape with a little face. Ten faces, twelve shapes and a color row; the app icon got the same treatment.
  • Profile like Cue: Assets (Mails, Computer), Configurations and Automations, each opening its own page.
  • Automations: schedules (cron), new email, local webhooks and group messages. Run now, pause, edit.
  • Email per agent: IMAP/SMTP with auto-detected servers for common providers, or Gmail via Composio. Tools to read, search and send, with approval before sending.
  • Computers: Docker containers, SPACE microVMs, WSL or this computer, with a live terminal and a file browser in the new Computer panel.
  • Skills in the Claude Code SKILL.md format: create, import from a URL, and let agents save their own.
  • Composio: connect 1000+ apps and let agents search and run actions.
  • Voice: talk with the microphone; ElevenLabs transcribes your voice and reads replies aloud, with a voice per agent.
  • Settings: Computers, Voice and About pages, Composio card in Apps, and a link to get help.
  • Website with docs, privacy policy and this changelog.

Changed

  • One-to-one chats drop avatars next to messages and use rounder bubbles; group chats keep them.
  • Events such as “Received an email” render as compact, expandable rows.
  • Agents now refuse to follow instructions found in emails, web pages and tool results unless you ask in the chat.

0.1.0 October 17, 2026

First release.

  • Agents with instructions, memory (per agent and shared) and streaming chat.
  • Group chats with @mentions, model-routed replies, hand-offs and a turn limit.
  • Providers by API key (OpenAI, Anthropic, xAI, OpenRouter, CheaperInference, Ollama, LM Studio, OpenAI-compatible) and the Codex / Claude CLIs.
  • MCP servers, local and by URL, with mcp.json import.
  • Free web search and page reading.
  • Approvals or autonomous mode, tray icon, English and Spanish, light and dark themes, and a CLI.
